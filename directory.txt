## Requirements and Setup

- Node.js and npm
- PostgreSQL with the `Users` table
- MongoDB
- Supabase project with a Storage bucket named `documents` for PDF uploads

Install and start the middleware:

```powershell
cd middleware
npm install
npm run dev
```

Configure `middleware/.env` with `DATABASE_URL`, `JWT_SECRET`, and `MONGODB_URI`. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` to enable document upload. `PORT` is optional and defaults to `5000`. Keep service credentials private and out of source control.

Install and start the client in a second terminal:

```powershell
cd client
npm install
npm run dev
```

Vite prints the local client URL, typically `http://localhost:5173`. The API base URL defaults to `http://localhost:5000`.

## API Overview

- `POST /api/auth/signup` - Create an account.
- `POST /api/auth/login` - Authenticate and receive a JWT.
- `POST /api/history/new` - Create a user history, optionally attaching a PDF.
- `GET /api/history/get` - Fetch the authenticated user's history.

See `middleware/API.md` for request formats and Thunder Client testing steps. History IDs currently use a constant value and are not unique.
