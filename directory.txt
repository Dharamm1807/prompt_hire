## Requirements and Setup

- Node.js and npm
- PostgreSQL with the `Users` table
- MongoDB
- Supabase project with a Storage bucket named `documents` for PDF uploads
- Groq API key for AI question and message generation

Install and start the middleware:

```powershell
cd middleware
npm install
npm run dev
```

Configure `middleware/.env` with `DATABASE_URL`, `JWT_SECRET`, `MONGODB_URI`, and `GROQ_API_KEY`. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` to enable document upload. `PORT` is optional and defaults to `5000`. Keep service credentials private and out of source control.

Install and start the client in a second terminal:

```powershell
cd client
npm install
npm run dev
```

Vite prints the local client URL, typically `http://localhost:5173`. The API base URL defaults to `http://localhost:5000`.

## API Overview

- `POST /api/auth/signup` - Create an account.
- `POST /api/auth/login` - Authenticate and receive a JWT.
- `POST /api/history/new` - Create a user history, optionally attach a PDF, and generate initial interview questions when PDF text is available.
- `GET /api/history/get` - Fetch the authenticated user's history.
- `POST /api/message/send` - Save a message and generate/save an AI reply.
- `POST /api/message/get` - Fetch saved messages for a history thread.

See `middleware/API.md` for request formats, AI behavior, responses, and Thunder Client testing steps.
