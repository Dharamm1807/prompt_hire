## Requirements and Setup

- Node.js and npm
- PostgreSQL with the `Users` table
- MongoDB
- Supabase project with a Storage bucket named `documents` for PDF uploads
- Groq API key for AI question and message generation
- Qdrant cloud or local deployment for RAG retrieval
- Python 3 environment for the knowledge-base loader and FastAPI retrieval service

Install and start the middleware:

```powershell
cd middleware
npm install
npm run dev
```

Configure `middleware/.env` with `DATABASE_URL`, `JWT_SECRET`, `MONGODB_URI`, and `GROQ_API_KEY`. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` to enable document upload. Set `RAG_URL=http://localhost:8000` if the RAG API is not running at its default URL. `PORT` is optional and defaults to `5000`. Keep service credentials private and out of source control.

Configure `rag/.env` with `QDRANT_URL` and `QDRANT_API_KEY`.

Install and start the client in a second terminal:

```powershell
cd client
npm install
npm run dev
```

Vite prints the local client URL, typically `http://localhost:5173`. The API base URL defaults to `http://localhost:5000`.

Start the RAG service in a separate terminal:

```powershell
cd rag
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python load.py
uvicorn retrieve_api:app --host 0.0.0.0 --port 8000
```

`load.py` should be run when `rag/data/kb.json` changes or the collection needs rebuilding. See `rag/AI.md` for embedding, retrieval, and question-generation details.

## API Overview

- `POST /api/auth/signup` - Create an account.
- `POST /api/auth/login` - Authenticate and receive a JWT.
- `POST /api/history/new` - Create a user history, optionally attach a PDF, and generate initial interview questions when PDF text is available.
- `GET /api/history/get` - Fetch the authenticated user's history.
- `POST /api/message/send` - Save a message and generate/save an AI reply.
- `POST /api/message/get` - Fetch saved messages for a history thread.
- RAG `GET /health` - Check whether the FastAPI retrieval service is running.
- RAG `POST /retrieve` - Retrieve question exemplars and other knowledge-base context for a candidate profile.

See `middleware/API.md` for request formats, AI behavior, responses, and Thunder Client testing steps.
